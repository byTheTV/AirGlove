AirGlove {version} · Windows 10/11 x64

1. Откройте AirGlove.exe. Симулятор сразу показывает жесты, состояние
   датчиков и движение виртуального курсора.
2. Включите перчатку и выберите Bluetooth или USB. Для USB закройте
   монитор последовательного порта. При необходимости укажите COM-порт.
3. Положите кисть горизонтально, выпрямите пальцы и нажмите «Калибровка».
   Держите кисть неподвижно, пока приложение не подтвердит готовность.
4. Нажмите «Включить системный ввод». Esc отключает управление, пока
   приложение запущено.
5. На вкладке «Профили» можно настроить действия мыши и клавиатуры.
   «Тренировка» проверяет жесты в окне приложения.

Для портативной версии сначала распакуйте ZIP в отдельную папку.
Профили хранятся в %LOCALAPPDATA%\AirGlove\profiles.json.
Записи телеметрии сохраняются в выбранную вами папку.
Микрофон используется только по вашему выбору для подтверждения
щелчка. Звук не записывается.
