# BNO055: фиолетовый модуль GY-BNO055 / CJMCU-055 вместо Adafruit

На первой версии схемы из Fritzing (`docs/schema_v1_fritzing.png`) нарисован синий модуль **Adafruit BNO055**:
в Fritzing есть только он.
Мы купили фиолетовый клон **GY-BNO055 (CJMCU-055)**. Микросхема та же (BNO055), библиотека та же
(`Adafruit_BNO055`). Отличаются только подписи пинов, перемычки и кварц.

## Соответствие пинов

| Adafruit BNO055 (схема) | GY-BNO055 (наш модуль) | Куда подключать                   | Пин BNO055     |
|-------------------------|------------------------|-----------------------------------|----------------|
| VIN                     | VCC                    | 3V3 (красная шина)                | VDD/VDDIO      |
| GND                     | GND                    | GND (чёрная шина)                 | GND            |
| SDA                     | **ATX**                | SDx канала TCA9548A               | COM0 (SDA/TX)  |
| SCL                     | **LRX**                | SCx канала TCA9548A               | COM1 (SCL/RX)  |
| ADR                     | **I2C**                | не подключать (или GND/3V3, см. ниже) | COM3 (адрес) |
| INT                     | INT                    | не используется                   | INT            |
| RST                     | **RES**                | не подключать (есть подтяжка)     | nRESET         |
| PS0 / PS1               | перемычки **S0 / S1**  | обе на GND → I²C                  | PS0 / PS1      |
| 3Vo                     | нет                    | -                                 | -              |
| -                       | BOOT                   | не подключать                     | nBOOT_LOAD     |

Подписи `ATX`/`LRX` взяты из режима UART (TX/RX). В режиме I²C на этих же ножках работают SDA/SCL.

## Что проверить перед пайкой

1. **Перемычки S0/S1.** Для I²C у обеих должна быть замкнута сторона «0» (на GND). Обычно модуль
   так и приходит, но проверьте мультиметром: PS0 = PS1 = 0 В.
2. **Адрес.** Его задаёт пин `I2C`: 0x28 при GND, 0x29 при 3V3. На многих GY-модулях он подтянут
   к питанию, и тогда адрес **0x29**, а у Adafruit по умолчанию 0x28. Каждый датчик стоит на своём
   канале TCA9548A, поэтому конфликта адресов нет. Просто запустите I²C-сканер на канале и передайте
   найденный адрес в конструктор: `Adafruit_BNO055(55, 0x29, &Wire)`.
3. **Кварц 32,768 кГц** лежит в пакете отдельно. Есть два варианта:
   - запаять его в два отверстия у верхнего края платы; тогда в коде `bno.setExtCrystalUse(true)`;
   - не паять и работать от внутреннего генератора: `bno.setExtCrystalUse(false)`. Точность
     ориентации немного ниже, для макета это допустимо.
4. **Питание** от 3,3 В, как на схеме. Подавать 5 В не нужно.
5. **Clock stretching.** BNO055 растягивает SCL. На ESP32-C3 при сбоях увеличьте таймаут:
   `Wire.setTimeOut(...)`. Частота шины 100 кГц.
